# 🤖 JARVISxSalim

> *"Your Personal AI Assistant — Iron Man's JARVIS, now on your desktop."*

JARVISxSalim is a full-featured AI assistant built with **Streamlit**, **Groq**, and **Agno**. It can chat, search the web, generate images, and speak responses — all with a stunning sci-fi interface.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 💬 **Smart Chat** | Powered by Groq's `openai/gpt-oss-120b` model |
| 🔍 **Web Search** | Real-time search via DuckDuckGo (no API key needed) |
| 🎨 **Image Generation** | AI image generation via Pollinations.ai (free, no key) |
| 🔊 **Text-to-Speech** | Natural female voice using Microsoft Edge Neural TTS |
| 🧠 **Conversation Memory** | Remembers context for natural conversations |
| 🎯 **Tech Interface** | Iron Man JARVIS themed UI with 3D holographic effects |
